# Biofilm Poroelastic Simulation Code

Companion code for the manuscript:

**Interfacial drainage regime as a coordinate linking biofilm mechanics and transport**

## Overview

This repository contains the publication-ready Python simulation code and numerical outputs for version **v3.0.1**.

The code implements a minimal one-dimensional linearised Biot/Terzaghi consolidation model for biofilm poroelastic drainage.

The script generates:

- Figure 2
- Figure 3
- Supplementary Figure S1 validation artwork

Figures 1 and 4 are conceptual or schematic and are not generated by this script.

## Publication artwork

Figures 2 and 3 are assembled as single numbered multi-panel artwork files:

- `Figure_2`: panels A-B over panels C-D
- `Figure_3`: panel A over panels B-C

The numbered figures are saved in both PNG and LZW-compressed TIFF formats.

- Figures 2 and 3: 500 dpi combination artwork
- Supplementary Figure S1: 1000 dpi line artwork

## Output files

The generated outputs are stored in:

`biofilm_sim_outputs/`

The output folder contains:

- `Figure_2.png`
- `Figure_2.tiff`
- `Figure_3.png`
- `Figure_3.tiff`
- `Figure_S1_Validation.png`
- `Figure_S1_Validation.tiff`

It also contains the source CSV files used for the plotted results.

## Requirements

Python 3.8 or newer is recommended.

Install the required packages with:

`python -m pip install -r requirements.txt`

The main dependencies are:

- NumPy
- SciPy
- Matplotlib
- Pillow

## Running the simulation

Run the script from the repository root with:

`python src/BiofilmPoroelasticSim.py`

The generated figures and CSV files will be written to:

`biofilm_sim_outputs/`
