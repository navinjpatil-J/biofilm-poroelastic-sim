# Biofilm Poroelastic Simulation Code

Companion code for the manuscript:

**Interfacial drainage regime as a coordinate linking biofilm mechanics and transport**

## Overview

This repository contains the publication-ready Python simulation code and numerical outputs for version **v3.0.1**.

The code implements a minimal one-dimensional linearised Biot/Terzaghi consolidation model for biofilm poroelastic drainage.

The script generates:

- Figure 2
- Figure 3
- Supplementary Figure S1 validation artwork

Figures 1 and 4 are conceptual or schematic and are not generated by this script.
